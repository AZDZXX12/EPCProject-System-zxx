# 甘特图问题排查指南

## 问题1: 看不到甘特图，只显示热力图

### 原因分析
1. **没有选择项目** - 顶部项目选择器未选择
2. **项目中无任务数据** - 当前项目没有任务
3. **容器高度问题** - CSS高度设置错误

### 解决方案

#### 步骤1: 检查是否选择项目
```
查看页面顶部是否显示：
"请先在顶部选择一个项目"

如果是 → 在顶部下拉框选择项目
```

#### 步骤2: 检查是否有任务数据
```
选择项目后，如果显示：
"暂无任务数据"

说明当前项目没有任务
```

#### 步骤3: 添加任务
两种方式：

**方式1: 手动添加**
```
1. 点击右上角 "添加任务" 按钮
2. 填写任务信息：
   - 任务名称：必填
   - 开始日期：必填
   - 工期：必填（天数）
   - 进度：可选
   - 负责人：可选
3. 点击确定
```

**方式2: 生成测试数据**
```
1. 在浏览器控制台（F12）执行：
   localStorage.setItem('test_mode', 'true')
2. 刷新页面
3. 点击 "生成测试数据" 按钮
4. 自动生成10个测试任务
```

## 问题2: 关键路径按钮点击后没有反应

### 原因
- 任务没有依赖关系
- 任务缺少开始/结束时间
- 存在循环依赖

### 解决方案
```
1. 确保任务有开始和结束时间
2. 添加任务依赖关系：
   - 双击任务打开编辑
   - 设置前置任务
3. 检查没有循环依赖（A依赖B，B依赖A）
```

## 问题3: 自动规划失败

### 原因
- 任务缺少持续天数
- 依赖关系错误
- 存在循环依赖

### 解决方案
```
1. 检查每个任务都有 duration（工期）
2. 检查依赖关系是否正确
3. 移除循环依赖
4. 重新点击 "自动规划" 按钮
```

## 问题4: 工作负载热力图显示异常

### 原因
- 任务日期格式错误
- 数据未正确加载

### 解决方案
```
1. 点击 "刷新" 按钮重新加载数据
2. 检查浏览器控制台是否有错误
3. 刷新整个页面
```

## 问题5: 延期任务没有变红

### 原因
- 任务进度已100%
- 任务结束时间未过期
- 样式未正确应用

### 解决方案
```
延期任务需要同时满足：
1. 结束时间 < 当前时间
2. 进度 < 100%

检查任务是否符合条件
```

## 快速测试流程

### 完整测试步骤
```
1. 选择项目（顶部下拉框）

2. 添加3个测试任务：
   任务A: 设计，3天，开始日期=今天
   任务B: 开发，5天，开始日期=今天+3天，依赖A
   任务C: 测试，2天，开始日期=今天+8天，依赖B

3. 测试自动规划：
   - 修改任务A的工期为5天
   - 点击 "自动规划"
   - 查看任务B和C的时间是否自动调整

4. 测试关键路径：
   - 点击 "关键路径" 按钮
   - 查看所有任务是否变红
   - （因为是串行依赖，都是关键路径）

5. 测试基线：
   - 点击 "创建基线"
   - 修改任务进度
   - 对比当前 vs 基线

6. 测试工作负载：
   - 查看热力图
   - 点击日期单元格
   - 查看任务列表
```

## 常见错误信息

### "can't access lexical declaration"
```
原因：循环依赖或导入顺序错误
解决：刷新页面，如果持续出现，清除浏览器缓存
```

### "请先在顶部选择一个项目"
```
原因：未选择项目
解决：在页面顶部的项目下拉框中选择一个项目
```

### "暂无任务数据"
```
原因：当前项目没有任务
解决：点击 "添加任务" 按钮创建任务
```

### "⚠️ 后端连接失败，使用本地模式"
```
原因：后端服务未启动或连接失败
解决：
1. 启动后端服务
2. 或继续使用离线模式（功能正常）
```

## 开发者调试

### 查看日志
```javascript
// 打开浏览器控制台（F12）

// 查看甘特图初始化日志
localStorage.setItem('debug', 'true');
location.reload();

// 查看当前任务数据
console.log(window.gantt?.getTaskByTime());

// 查看依赖关系
console.log(window.gantt?.getLinks?.());
```

### 手动初始化
```javascript
// 如果甘特图未显示，尝试手动初始化
if (window.gantt && document.querySelector('.gantt-container')) {
  window.gantt.init(document.querySelector('.gantt-container'));
  window.gantt.render();
}
```

### 清除缓存
```javascript
// 清除所有甘特图缓存
Object.keys(localStorage).forEach(key => {
  if (key.startsWith('gantt_')) {
    localStorage.removeItem(key);
  }
});
location.reload();
```

## 性能优化建议

### 大数据量（100+任务）
```
1. 启用虚拟滚动
2. 减少自动保存频率
3. 关闭关键路径实时计算
4. 使用日期筛选
```

### 网络慢
```
1. 使用离线优先模式（已默认启用）
2. 减少刷新频率
3. 使用本地缓存
```

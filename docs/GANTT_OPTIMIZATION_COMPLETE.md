### 4. 配色方案

#### 状态配色
```typescript

in_progress: '#4CAF50'  // 绿色
completed: '#2196F3'    // 蓝色
delayed: '#F44336'      // 红色
```


```typescript

milestone: '#FFD700'  // 里程碑
```

# 甘特图优化功能快速使用指南

> 刷新页面后立即可用！

---

## 🚀 新增功能按钮

查看甘特图页面顶部工具栏，从左到右依次为：

```
[日/周/月] [创建基线] [关键路径] [自动规划] [添加任务] [刷新] [同步]
```

---

## 📝 功能使用说明

### 1. 创建基线 📸

**作用**：保存当前项目计划作为对比基准

**使用步骤**：
1. 点击 **"创建基线"** 按钮
2. 系统自动创建快照（命名：基线_2025/11/23）
3. 显示成功提示

**应用场景**：
- 项目启动时创建初始基线
- 重大调整前保存当前状态
- 定期创建版本快照

---

### 2. 关键路径分析 🔴

**作用**：识别项目中的瓶颈任务（CPM算法）

**使用步骤**：
1. 点击 **"关键路径"** 按钮
2. 关键任务自动变为红色高亮
3. 查看分析报告：
   - 关键任务数量
   - 总工期天数
4. 再次点击按钮取消高亮

**视觉效果**：
- 🔴 关键任务：红色边框 + 光晕
- 🔴 关键连接线：红色加粗
- Tooltip 显示 "🔴 关键路径" 徽章

**关键任务定义**：
- 松弛时间为 0 的任务
- 延期会导致整个项目延期
- 需要优先保障的任务

---

### 3. 自动规划 🤖

**作用**：根据依赖关系自动计算所有任务时间

**使用步骤**：
1. 确保任务已设置：
   - 持续时间（天数）
   - 依赖关系
2. 点击 **"自动规划"** 按钮
3. 系统自动计算并更新所有任务的开始/结束时间

**配置说明**：
- 工作日：周一至周五
- 跳过：周末和节假日
- 起始：当天

**依赖类型支持**：
- FS：完成-开始（最常用）
- SS：开始-开始
- FF：完成-完成
- SF：开始-完成

---

### 4. 工作负载热力图 🔥

**位置**：甘特图下方自动显示

**功能说明**：
- 自动计算每日任务密度
- 颜色越深 = 任务越多
- 点击日期查看详细任务列表

**颜色含义**：
- ⬜ 灰色：无任务
- 🟨 浅红：1-3个任务（轻度）
- 🟧 中红：4-6个任务（中度）
- 🟥 深红：7+个任务（高负载⚠️）

**使用建议**：
- 识别资源瓶颈日期
- 优化任务分配
- 避免过度集中


## ⚠️ 注意事项

### 自动规划前提
- ✅ 任务必须设置持续天数
- ✅ 依赖关系必须正确无循环
- ❌ 不要在手动设置时间后立即自动规划

### 关键路径分析前提
- ✅ 所有任务必须有开始和结束时间
- ✅ 依赖关系必须完整
- ❌ 循环依赖会导致分析失败

### 基线使用建议
- ✅ 项目启动时必须创建
- ✅ 重大里程碑前创建
- ✅ 定期创建（每周/每月）
- ❌ 不要频繁创建（避免混乱）

## 🔧 常见问题

### Q1: 点击"关键路径"后没有红色高亮？
**A**: 检查以下条件：
- 所有任务都有开始/结束时间
- 存在依赖关系
- 没有循环依赖

### Q2: 自动规划后时间不对？
**A**: 检查：
- 任务持续天数是否正确
- 依赖关系是否正确
- 项目开始日期是否合理

### Q3: 工作负载热力图显示异常？
**A**: 刷新页面重新加载数据

### Q4: 延期任务没有变红？
**A**: 检查：
- 任务结束时间是否已过期
- 任务进度是否 < 100%

## 🎯 最佳实践

### 日常使用流程
```
每日：
1. 更新任务进度
2. 查看延期任务（自动红色标识）
3. 查看工作负载热力图

每周：
1. 点击"关键路径"分析
2. 优先处理关键任务
3. 调整资源分配
4. 创建周基线

每月：
1. 与基线对比分析
2. 总结偏差原因
3. 调整后续计划
4. 创建月基线
```

### 项目管理技巧

**识别风险**：
- 关键路径上的延期任务 = 高风险⚠️
- 工作负载深红色日期 = 资源风险
- 连续延期任务 = 流程问题

**优化策略**：
- 关键任务加资源
- 非关键任务可延后
- 高负载日期分散任务
- 并行执行无依赖任务

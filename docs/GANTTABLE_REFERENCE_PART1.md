## 📋 产品定位

### 核心价值
Ganttable 是一款**融合 AI 智能规划**的专业工具，以**直观的甘特图为核心载体**，帮助团队：
- 清晰可视化项目进度
- 管理任务依赖与时间节点
- 实现项目全流程的精细化管理与高效推进

### 特色定位
1. **AI 驱动** - 自然语言生成项目计划
2. **可视化核心** - 甘特图作为主要交互界面
3. **全流程管理** - 从规划到执行到分析的完整闭环
4. **多维度分析** - 工时、进度、成本、风险多角度监控

## 🤖 AI 智能功能

### 1. 文本生成甘特图（核心亮点）

#### 1.1 主题大纲创建（推荐方式）

**流程设计**：
```
用户输入 → AI 生成大纲 → 用户编辑 → 一键创建甘特图
```

**示例**：
```
输入: "给我一个校园文化节活动方案"

AI 自动生成:
├── 策划阶段
│   ├── 主题确定
│   ├── 预算编制
│   └── 场地申请
├── 执行阶段
│   ├── 宣传推广
│   ├── 活动布置
│   └── 现场执行
└── 收尾阶段
    ├── 场地清理
    └── 总结报告
```

**核心能力**：
- ✅ 自动识别关键阶段
- ✅ 自动生成 WBS（工作分解结构）
- ✅ 自动捕捉任务依赖关系
- ✅ 轻量编辑能力（修改任务/依赖）

#### 1.2 五种自由文本输入模式

| 模式 | 适用场景 | 准确度 | 示例 |
|------|---------|--------|------|
| **1. 自由描述型** | 初次使用/不熟悉流程 | ⭐⭐⭐ | "我需要一个1500平米自动化厂房施工的项目流程" |
| **2. 结构化清单** | 已有明确阶段划分 | ⭐⭐⭐⭐ | "一、策划阶段 竞品分析 方案设计 二、执行阶段..." |
| **3. 带工时任务集** | 包含时长信息 | ⭐⭐⭐⭐⭐ | "1. 方案策划（3天） 2. 素材设计（5天）..." |
| **4. 精确时间锚点** | 明确时间要求 | ⭐⭐⭐⭐⭐ | "数据迁移 2023/10/01-2023/10/03 培训..." |
| **5. 全要素模板型** | 完整项目信息 | ⭐⭐⭐⭐⭐ | 包含任务/时间/依赖/负责人全要素 |

**实现建议**：
```typescript
// AI 输入解析接口设计
interface AIGanttInput {
  text: string;              // 用户输入文本
  mode: 'auto' | 'outline' | 'structured' | 'timed' | 'full'; // 识别模式
  projectStartDate?: Date;   // 项目开始时间
}

interface AIGanttOutput {
  stages: Stage[];           // 项目阶段
  tasks: Task[];             // 任务列表
  dependencies: Dependency[]; // 依赖关系
  confidence: number;        // 置信度评分
}
```

### 2. 计划分解（AI 辅助优化）

#### 2.1 生成阶段
- AI 快速分析并生成逻辑清晰的项目阶段
- 涵盖起始、执行、结束等关键环节
- 根据项目特性智能划分细致阶段

#### 2.2 拆解阶段任务
- AI 智能拆解阶段下的具体任务
- 协助补全和检查每个阶段的关键任务
- 确保任务全面性和完整性

#### 2.3 任务拆分（科学化）
**核心原则**：
- ✅ 每个任务尽可能只由一个角色执行
- ✅ 任务粒度合理，可落地执行
- ✅ 避免任务分配不均或难度过大

## 📊 甘特图编辑器 - 20+核心功能

### 1. 任务条显示信息（可定制化）

**核心设计**：
- 每个任务条右侧显示任务名称
- 支持显示任务的其他字段信息
- 通过配置面板勾选需要显示的字段

**可显示字段示例**：
- 任务名称
- 负责人
- 完成度（百分比）
- 剩余天数
- 优先级
- 状态标签

### 2. 任务依赖关系（拖拽创建）

**核心交互**：
- 通过拖拽方式创建任务依赖
- 链接线条清晰展现先后顺序
- 支持四种依赖类型

**依赖类型**：
1. **FS (Finish-to-Start)** - 完成到开始（最常用）
2. **SS (Start-to-Start)** - 开始到开始
3. **FF (Finish-to-Finish)** - 完成到完成
4. **SF (Start-to-Finish)** - 开始到完成

### 3. 甘特图配色（灵活定制）

**着色维度**：
- 按状态着色（进行中/已完成/延期）
- 按优先级着色（高/中/低）
- 按负责人着色
- 按项目阶段着色
- 自定义颜色规则

### 4. 任务分组（模块化展示）

**核心功能**：
- 任务分组聚合功能
- 相同分组的任务整合至一个模块
- 模块颜色根据分组字段自动填充
- 支持展开/折叠分组

### 5. 自动规划任务起止时间（核心能力）

**功能价值**：
- ✅ 只需输入任务天数
- ✅ 系统根据依赖关系自动计算起止时间
- ✅ 任务变动时自动重新计算
- ✅ 告别手动计算的繁琐和错误

### 6. 完成度自动计算（三种模式）

#### 6.1 基于工时计算（最精确）
```
完成度 = 实际工时 / 预计工时 × 100%
```

#### 6.2 基于进度字段计算（最简便）
- 手动更新任务进度字段（0-100%）
- 父任务进度 = 子任务进度平均值

#### 6.3 基于当前时间计算（最简单）
```
完成度 = (当前日期 - 开始日期) / (结束日期 - 开始日期) × 100%
```

## 🔍 高级分析功能

### 1. 项目基线（Plan vs Actual）

#### 核心概念
项目基线是**项目启动时的初始计划蓝图**，用于：
- ✅ 对比计划变动
- ✅ 识别延期风险
- ✅ 追踪时间偏差

#### 视觉呈现
```
任务条设计：
┌─────────────────────┐  ← 当前实际任务条（彩色）
│  任务A  [======>   ]│
└─────────────────────┘
▔▔▔▔▔▔▔▔▔▔▔▔▔         ← 基线任务条（灰色底部）
```

#### 功能特性

**1. 添加项目基线**
- 点击"添加基线"按钮
- 系统快照当前所有任务的时间安排
- 基线条显示在任务条底部（灰色）

**2. 自动计算任务延期**
- 系统自动计算延期天数
- 可按延期天数筛选任务
- 支持延期预警

**3. 基线回滚**
- 一键回滚到基线状态
- 所有任务时间恢复到基线快照

### 2. 工作负载分析（日期热力图）

**视觉呈现**：
```
日期热力图（甘特图底部）
┌───┬───┬───┬───┬───┬───┬───┐
│   │   │░░░│███│░░░│   │   │  ← 颜色深浅表示任务密度
└───┴───┴───┴───┴───┴───┴───┘
 1日  2日  3日  4日  5日  6日  7日
```

**颜色指示**：
- **浅红色** - 任务较少，资源宽松
- **中等红色** - 任务适中
- **深红色** - 任务繁重，资源紧张⚠️

**交互功能**：
- 点击日期单元格
- 快速定位并高亮该日所有任务

### 3. 关键路径分析（Critical Path Method）

#### 核心概念
关键路径是项目中**最长、最关键的任务链**，决定项目的**最短完成时间**。

#### 功能价值
- ✅ 识别项目瓶颈
- ✅ 优化资源分配
- ✅ 制定应急计划
- ✅ 提前应对延误

#### 视觉呈现
- 关键路径任务显示为红色
- 依赖连接线加粗显示
- 任务名称标记⚠️图标

### 4. 浮动时间分析（Float Time）

#### 核心概念
浮动时间是指在**不影响项目总工期**的前提下，任务可以**延迟或提前的时间范围**。

#### 功能价值
- ✅ 提供任务调整的灵活性
- ✅ 优化资源分配
- ✅ 应对潜在风险
- ✅ 区分任务优先级

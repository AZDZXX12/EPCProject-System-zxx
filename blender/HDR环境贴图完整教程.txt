🌅 什么是 HDR / HDRI？

HDR = High Dynamic Range (高动态范围)
HDRI = HDR Image (高动态范围图像)

用途：
- 为场景提供真实的环境照明
- 创建反射效果（金属、玻璃）
- 快速获得专业的光照效果
- 替代传统的灯光设置

常见格式：.hdr, .exr

✅ 方法1：使用 Shading 工作区（最常用）⭐⭐⭐⭐⭐

【步骤详解】

1. 切换到 Shading 工作区
   ┌────────────────────────────────────────┐
   │ 顶部工作区标签：                       │
   │ Layout | Modeling | Shading | ...      │
   │                      ↑ 点这个           │
   └────────────────────────────────────────┘

2. 切换到 World（世界）节点
   ┌────────────────────────────────────────┐
   │ Shader Editor（着色器编辑器）底部：   │
   │ [🔘Object] [🔘World]                  │
   │             ↑ 点这个                   │
   └────────────────────────────────────────┘

3. 你会看到默认的节点：
   ┌────────────────────────────────────────┐
   │ [Background] → [World Output]          │
   └────────────────────────────────────────┘

4. 添加环境贴图节点
   ┌────────────────────────────────────────┐
   │ 方法A: 按 Shift+A                      │
   │   → Texture                            │
   │   → Environment Texture                │
   │                                        │
   │ 方法B: Add 菜单                        │
   │   → Texture → Environment Texture      │
   └────────────────────────────────────────┘

5. 连接节点
   ┌────────────────────────────────────────┐
   │ [Environment Texture] → [Background]   │
   │         Color 输出    →   Color 输入   │
   └────────────────────────────────────────┘

   最终节点结构：
   [Environment Texture] → [Background] → [World Output]

6. 加载 HDR 图像
   ┌────────────────────────────────────────┐
   │ 在 Environment Texture 节点上：        │
   │ 点击 "Open" 或文件夹图标               │
   │ 浏览到您的 .hdr 或 .exr 文件          │
   │ 选择文件 → Open Image                 │
   └────────────────────────────────────────┘

7. 查看效果
   ┌────────────────────────────────────────┐
   │ 在 3D 视图中按 Z 键                    │
   │ 选择 "Rendered"                        │
   │ 或者                                   │
   │ 选择 "Material Preview"                │
   └────────────────────────────────────────┘

✓ 完成！场景现在使用 HDR 照明了！

✅ 方法2：快速方法（不用节点）⭐⭐⭐⭐

【适合初学者】

1. 打开 Shading 工作区

2. 在右侧属性面板找到 World Properties
   （地球图标 🌍）

3. 在 "Surface" 下，点击 Background 旁的小点
   ┌────────────────────────────────────────┐
   │ Surface:                               │
   │ Background  [⚫]                        │
   │              ↑ 点这个小点               │
   └────────────────────────────────────────┘

4. 选择 "Environment Texture"

5. 在出现的 Color 选项下，点击文件夹图标

6. 选择您的 HDR 文件

✓ 完成！

🎨 调整 HDR 效果

【旋转环境】

有时 HDR 的方向不对，需要旋转：

1. 在节点编辑器中，添加 Mapping 节点：
   Shift+A → Vector → Mapping

2. 添加 Texture Coordinate 节点：
   Shift+A → Input → Texture Coordinate

3. 连接节点：
   ┌────────────────────────────────────────────────────┐
   │ [Texture Coordinate]                               │
   │     Generated → [Mapping]                          │
   │                   Vector → [Environment Texture]   │
   │                              Color → [Background]  │
   └────────────────────────────────────────────────────┘

4. 在 Mapping 节点中，调整 Rotation 的 Z 值
   ┌────────────────────────────────────────┐
   │ Rotation:                              │
   │ Z: 90°  (尝试不同角度)                 │
   └────────────────────────────────────────┘


【调整亮度】

1. 在 Background 节点中，调整 Strength 值
   ┌────────────────────────────────────────┐
   │ Strength: 1.0  (默认)                  │
   │          0.5  (变暗)                   │
   │          2.0  (变亮)                   │
   └────────────────────────────────────────┘


【调整颜色】

1. 在 Environment Texture 和 Background 之间
   添加 ColorRamp 或 Hue/Saturation 节点

2. Shift+A → Color → Hue Saturation Value

3. 调整颜色、饱和度、亮度


【模糊背景】

如果不想看到 HDR 背景，只要照明：

1. 在渲染设置中：
   Film → ☑ Transparent

2. 或添加 Light Path 节点控制可见性

📝 完整示例：手动添加 HDR 的完整流程

【场景】您从 Poly Haven 下载了一个 HDR

假设文件：D:\HDRI\studio_small_03_4k.hdr

步骤：

1. 打开 Blender，新建场景

2. 切换到 Shading 工作区
   （顶部标签）

3. 在 Shader Editor 底部，点击 [🔘World]

4. 按 Shift+A
   → Texture → Environment Texture

5. 拖动 Environment Texture 节点
   连接到 Background 节点：
   Color (黄色) → Color (黄色)

6. 在 Environment Texture 节点
   点击 "Open" 文件夹图标

7. 浏览到：D:\HDRI\studio_small_03_4k.hdr

8. 点击 "Open Image"

9. 在 3D 视图中，按 Z → Rendered

10. 看到效果！🎉

调整（可选）：

11. 添加旋转控制：
    - Shift+A → Input → Texture Coordinate
    - Shift+A → Vector → Mapping
    - 连接：Generated → Vector → Environment Texture
    - 调整 Mapping 的 Rotation Z

12. 调整亮度：
    - Background 节点 → Strength: 调整数值

13. 保存场景 Ctrl+S

✓ 完成！

💡 常见问题

Q: 添加 HDR 后看不到效果？
A: 
1. 检查渲染引擎是 Cycles 或 Eevee（不是 Workbench）
2. 按 Z 键切换到 "Material Preview" 或 "Rendered"
3. 检查节点是否正确连接

Q: HDR 图像显示为紫色/粉色？
A: 
- 文件路径丢失或文件损坏
- 重新加载图像：点击文件夹图标重新选择

Q: 场景太亮或太暗？
A: 调整 Background 节点的 Strength 值

Q: HDR 背景不想显示在渲染中？
A: 
- Render Properties → Film → ☑ Transparent
- 或在相机设置中调整

Q: HDR 文件太大，Blender 很慢？
A: 
- 使用较低分辨率（2K 或 4K 而不是 16K）
- 4K 通常足够用于照明

Q: 怎么同时使用 HDR 和其他灯光？
A: 
- 可以！HDR 提供环境光
- 添加 Area Light、Point Light 等作为主光源
- 降低 HDR 的 Strength，增加灯光

🎯 推荐的 HDR 工作流程

【快速预览】
1. 使用 1K 或 2K 分辨率
2. Strength: 1.0

【最终渲染】
1. 使用 4K 或 8K 分辨率
2. 调整 Strength 到合适亮度
3. 添加旋转调整方向

【户外场景】
- 使用户外 HDRI（天空、森林等）
- Strength: 1.0-1.5

【室内场景】
- 使用室内/工作室 HDRI
- Strength: 0.5-1.0
- 可能需要额外的灯光

【产品渲染】
- 使用工作室 HDRI
- Strength: 1.5-2.0
- 添加柔光箱、环形灯等

# Blender编译 - 避开winrdlv3和sdhelper2加密的技术方案

## 问题分析

winrdlv3和sdhelper2是企业级文档加密软件，会：
- 自动加密特定目录下的新文件
- 监控和拦截可执行文件
- 对新生成的EXE进行加密或阻止运行

## 实用解决方案

### 方案1：使用临时RAM盘编译（推荐⭐⭐⭐⭐⭐）

加密软件通常不监控RAM盘，这是最有效的方法。

```batch
# 使用 ImDisk 或 OSFMount 创建RAM盘
# 1. 下载安装 ImDisk Toolkit
# 2. 创建一个10GB的RAM盘（盘符R:）
# 3. 在R盘进行编译

set RAMDISK=R:
cd /d %RAMDISK%
git clone https://projects.blender.org/blender/blender.git
cd blender
mkdir build && cd build
cmake .. -G "Visual Studio 17 2022"
cmake --build . --config Release
```

### 方案2：修改文件扩展名欺骗

编译时输出为非标准扩展名，使用时改回：

```cmake
# 在CMakeLists.txt中添加
set_target_properties(blender PROPERTIES 
    OUTPUT_NAME "blender"
    SUFFIX ".tmp"  # 临时输出为.tmp
)
```

然后用脚本重命名：
```batch
copy /b blender.tmp blender.exe
```

### 方案3：使用UPX压缩+加壳

UPX压缩可以改变文件特征，减少被识别：

```batch
# 下载 UPX
# https://github.com/upx/upx/releases

upx --best --lzma blender.exe -o blender_packed.exe
```

### 方案4：静态编译到单文件

减少DLL依赖，避免多文件被加密：

```cmake
cmake .. ^
    -DWITH_WINDOWS_BUNDLE_CRT=ON ^
    -DWITH_STATIC_LIBS=ON ^
    -DWITH_PYTHON_INSTALL_NUMPY=OFF
```

### 方案5：编译到网络路径

网络路径通常不被监控：

```batch
# 映射网络驱动器（可以是本机共享）
net use Z: \\localhost\BuildShare

cd /d Z:\
# 在Z盘进行编译
```

### 方案6：修改PE头时间戳

让文件看起来像旧文件：

```python
# modify_timestamp.py
import pefile
import time

pe = pefile.PE('blender.exe')
# 设置为2020年的时间戳
pe.FILE_HEADER.TimeDateStamp = 1577836800
pe.write('blender_modified.exe')
```

### 方案7：Docker/WSL2编译

在Linux子系统编译，避开Windows监控：

```bash
# 在WSL2中
git clone https://projects.blender.org/blender/blender.git
cd blender
make update
make
# 编译完后拷贝到Windows
```

### 方案8：使用便携式打包

用便携式格式打包，不触发监控：

```batch
# 使用7-Zip自解压格式
7z a -sfx blender_portable.exe build\bin\Release\*
```

## 推荐组合方案

### 最佳实践：RAM盘 + UPX + 签名

```batch
@echo off
echo 步骤1: 在RAM盘编译
R:
cd blender\build
cmake --build . --config Release

echo 步骤2: UPX压缩
upx --best bin\Release\blender.exe

echo 步骤3: 复制到安全位置
xcopy /E /I bin\Release D:\SafeApps\Blender
```

## 配置加密软件例外

### 如果有管理员权限：

1. **winrdlv3配置**：
   - 打开控制台，添加例外路径
   - 设置进程例外：cmake.exe, msbuild.exe
   - 添加文件类型例外：*.tmp, *.obj

2. **sdhelper2配置**：
   - 进入设置 → 例外规则
   - 添加开发目录到白名单
   - 设置编译工具为可信进程

## 终极方案：虚拟机隔离

如果以上都不行，使用虚拟机：

```
1. 安装 VirtualBox/VMware
2. 创建Windows 10虚拟机
3. 不安装加密软件
4. 在虚拟机内进行所有开发
5. 通过共享文件夹传输最终产品
```

## 注意事项

- 这些方法都是合法的技术手段
- 仅用于自己的开发环境
- 如果是公司电脑，建议咨询IT部门
- 保留原始源码和编译记录

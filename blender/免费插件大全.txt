1. NODE WRANGLER (内置插件 - 材质节点增强)
================================================================

Status: FREE - Built-in Blender
Function: 快速材质预览、节点管理

How to Enable:
Edit > Preferences > Add-ons > Search "Node Wrangler" > ✓ Enable

Usage:
- Ctrl+Shift+Click on texture node = Preview
- Ctrl+T = Add texture setup automatically
- Super useful for material editing!

================================================================
2. EXTRA OBJECTS (内置插件 - 额外物体)
================================================================

Status: FREE - Built-in Blender
Function: 添加更多基础物体（齿轮、管道等）

How to Enable:
Edit > Preferences > Add-ons > Search "Extra Objects" > ✓ Enable

Includes:
- Add Mesh: Extra Objects
- Add Curve: Extra Objects
- Gears, Pipes, Rocks, etc.

================================================================

HOW TO MANUALLY ADD MATERIALS:
================================================================

1. Go to website (e.g., polyhaven.com)
2. Download texture (choose 4K or 2K)
3. In Blender: Select object
4. Go to Shading workspace
5. Add > Texture > Image Texture
6. Open downloaded image
7. Done!

Or use Node Wrangler (Ctrl+Shift+T) for automatic setup!

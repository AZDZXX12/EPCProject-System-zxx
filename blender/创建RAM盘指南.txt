RAM盘是最有效的避开加密软件的方法！
加密软件驱动通常不监控内存文件系统。

═══════════════════════════════════════════════════════════════

📋 准备工作

检查您的内存：
- 至少需要：16GB物理内存（分配10GB给RAM盘）
- 推荐配置：32GB物理内存（分配20GB给RAM盘）

═══════════════════════════════════════════════════════════════

方法1：使用 ImDisk Toolkit（推荐）⭐⭐⭐⭐⭐

步骤：

1. 下载 ImDisk Toolkit
   网址：https://sourceforge.net/projects/imdisk-toolkit/
   或直接搜索："ImDisk Toolkit download"

2. 安装 ImDisk Toolkit
   - 双击安装包
   - 全部使用默认选项
   - 完成安装

3. 创建RAM盘
   
   a) 打开 RamDisk Configuration（开始菜单中找到）
   
   b) 设置参数：
      Size: 10240 MB（10GB）或更大
      Drive Letter: R:（或其他可用盘符）
      File System: NTFS
      ☑ Allocate memory dynamically
      
   c) 点击 "OK" 创建
   
   d) 几秒钟后，您会看到新的 R: 盘符

4. 验证
   - 打开"我的电脑"
   - 应该看到"R盘（RAM盘）"
   - 容量约10GB

5. 开机自动创建（可选）
   - 在RamDisk Configuration中
   - ☑ Load at Windows startup

═══════════════════════════════════════════════════════════════

方法2：使用 OSFMount（备选）⭐⭐⭐⭐

步骤：

1. 下载 OSFMount
   网址：https://www.osforensics.com/tools/mount-disk-images.html

2. 安装并打开 OSFMount

3. 创建RAM盘
   - 点击 "Mount new..."
   - Source: "Empty RAM drive"
   - Size: 10240 MB
   - Drive letter: R:
   - ☑ Format as: NTFS
   - ☑ Mount as fixed drive
   - 点击 OK

4. 保存配置（开机自动挂载）
   - File → Save mount as service
   - 设置服务名称

═══════════════════════════════════════════════════════════════

方法3：使用 Windows 内置（不推荐，较复杂）

PowerShell命令：
```powershell
# 需要管理员权限
$size = 10GB
$driveLetter = "R"
imdisk -a -s $size -m ${driveLetter}: -p "/fs:ntfs /q /y"
```

🎯 使用RAM盘编译

创建好RAM盘后：

1. 打开命令提示符
2. 输入：R:
3. 克隆源码到RAM盘：
   git clone https://projects.blender.org/blender/blender.git
4. 运行编译脚本：
   cd C:\Users\Administrator\Desktop\Z1D2
   build_on_ramdisk.bat

═══════════════════════════════════════════════════════════════

⚠️ 重要注意事项

1. 数据易失性
   ⚠️ RAM盘中的数据在关机后会丢失！
   ✓ 编译完成后立即复制EXE到硬盘
   
2. 内存占用
   - RAM盘会占用物理内存
   - 如果内存不足会影响系统性能
   - 编译时建议关闭其他大型程序
   
3. 自动备份（可选）
   - ImDisk支持自动保存到硬盘
   - 关机前自动备份，开机后恢复

═══════════════════════════════════════════════════════════════

🔧 故障排除

Q1: 创建失败"内存不足"
A: 减小RAM盘大小或关闭其他程序

Q2: 无法格式化为NTFS
A: 以管理员权限运行软件

Q3: 盘符冲突
A: 选择其他未使用的盘符（如S:、T:等）

Q4: 性能慢
A: 检查"动态分配"是否启用

Q5: 关机后丢失数据
A: 这是正常的！记得复制重要文件到硬盘

═══════════════════════════════════════════════════════════════

💡 性能优化建议

1. 编译器临时文件也放RAM盘
   set TEMP=R:\temp
   set TMP=R:\temp

2. 使用SSD存放源码（首次下载）
   然后复制到RAM盘编译

3. 分配适当大小
   - Blender编译需要：约8-12GB
   - 留出余量：建议15-20GB

═══════════════════════════════════════════════════════════════

📊 性能对比

编译Blender（完整构建）：

硬盘（HDD）：    60-90分钟
固态盘（SSD）：  30-45分钟
RAM盘：          15-25分钟  ⚡

同时：RAM盘完全绕过文件监控！

✅ 验证RAM盘工作正常

测试步骤：
1. 在R盘创建文件：echo test > R:\test.txt
2. 检查是否被加密（查看文件属性）
3. 如果没有被加密标记，说明加密软件未监控RAM盘

🎓 工作流程示例

理想的开发流程：

1. 首次设置
   → 创建RAM盘（R:）
   → 克隆Blender源码到 R:\blender
   → 下载预编译库

2. 日常开发
   → 修改源码（可在硬盘或RAM盘）
   → 同步修改到 R:\blender
   → 在RAM盘编译
   → 复制成品EXE到硬盘安全位置

3. 关机前
   → 确认EXE已复制到硬盘
   → 源码修改已提交到Git
   → 关机（RAM盘内容会丢失）

📥 如何升级到最新 4.2 LTS

【检查当前版本】
在 Blender 中：
Help → About Blender
查看版本号

【下载最新版本】
1. 访问：https://www.blender.org/download/lts/
2. 选择 Blender 4.2 LTS
3. 选择 Windows 64-bit
4. 下载安装包

【安装方法】

方法1: 便携式安装（推荐）
1. 下载 .zip 版本
2. 解压到：D:\Blender42LTS\
   ⚠️ 使用纯英文路径！
3. 运行 blender.exe
4. 不会覆盖旧版本

方法2: 安装程序
1. 下载 .msi 安装包
2. 运行安装程序
3. 选择安装路径（英文路径）
4. 完成安装

【迁移设置和插件】

自动迁移：
首次启动 4.2 时会提示：
"Copy previous settings?"
点击 "Copy Previous Settings"
会自动从 3.0 迁移设置

手动迁移插件：
1. 旧版本：%APPDATA%\Blender Foundation\Blender\3.0\
2. 复制 scripts\addons\ 到
3. 新版本：%APPDATA%\Blender Foundation\Blender\4.2\scripts\addons\
4. 在新版本中重新启用插件

⚠️ 注意：某些插件可能需要更新版本！

【迁移 BlenderKit 下载的模型】

方法1: 共享数据
1. Edit → Preferences → Add-ons → BlenderKit
2. Global Directory 指向原来的位置
3. 不需要重新下载

方法2: 复制数据
1. 从旧版本 blenderkit_data 文件夹
2. 复制到新版本对应位置

⚠️ 升级注意事项

【插件兼容性】

检查插件是否支持 4.2：
- BlenderKit: ✓ 支持（可能需要更新）
- Poly Haven Assets: ✓ 支持
- 其他第三方插件: 需要检查

更新插件：
1. 访问插件官网
2. 下载 4.2 兼容版本
3. 重新安装

【项目兼容性】

- 3.x 项目可以在 4.2 中打开 ✓
- 但 4.2 项目不能在 3.x 中打开 ✗

建议：
1. 旧项目：保留 3.0.1 完成它们
2. 新项目：使用 4.2
3. 或者：在 4.2 中打开旧项目，另存为新文件

【性能优化】

升级到 4.2 后：
1. 更新显卡驱动（重要！）
2. Edit → Preferences → System
3. 检查 Cycles 渲染设备（CUDA/OptiX/HIP）
4. 启用新功能：EEVEE Next

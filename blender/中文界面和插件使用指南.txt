📍 Poly Haven插件在哪里？

插件已经安装并启用，但需要先配置才能看到资产！

【关键步骤】必须先配置资产库：

1. 打开Blender
2. 编辑 → 首选项（或按 F4 → Preferences）
3. 左侧选择：文件路径 (File Paths)
4. 找到：资产库 (Asset Libraries)
5. 点击右侧的 '+' 按钮
6. 输入名称：Poly Haven
7. 选择路径（需要4GB空间）：
   推荐：D:\Blender Assets\Poly Haven
   或：C:\Users\Administrator\Documents\Blender Assets

8. 点击 OK 保存

═══════════════════════════════════════════════════════════════

🎨 如何打开Poly Haven资产？

配置好资产库后：

【方法1】通过编辑器切换（推荐）

1. 在Blender顶部找到当前编辑器图标
   （默认可能是3D视图的图标）
2. 点击图标，会出现编辑器类型菜单
3. 选择：Asset Browser（资产浏览器）

【方法2】通过快捷键

1. 按 Shift+F1
2. 选择 Asset Browser

【方法3】分割窗口

1. 鼠标移到编辑器边角
2. 右键 → 水平分割 或 垂直分割
3. 在新窗口选择 Asset Browser

═══════════════════════════════════════════════════════════════

📥 下载Poly Haven资产

打开资产浏览器后：

1. 在顶部下拉菜单选择 "Poly Haven"
   （如果看不到，说明资产库还没配置好）

2. 顶部工具栏会出现 "Fetch Assets" 按钮
   点击它开始下载

3. 等待下载完成（约3.3GB，首次需要30-60分钟）

4. 下载完成后可以看到：
   - HDRIs（HDRI环境贴图）
   - Textures（PBR纹理）
   - Models（3D模型）

═══════════════════════════════════════════════════════════════

🚀 使用Poly Haven资产

【导入HDRI环境】
1. 在资产浏览器找到 HDRIs 分类
2. 选择一个HDRI
3. 直接拖拽到3D视图
4. 自动应用到场景环境
5. 按 Z → Rendered 查看效果

【导入材质】
1. 找到 Textures 分类
2. 选择一个材质
3. 拖拽到3D对象上
4. 自动创建完整的PBR材质节点

【导入3D模型】
1. 找到 Models 分类
2. 选择模型
3. 拖拽到场景
4. 立即使用

⚡ Poly Haven插件特殊功能

【更改纹理分辨率】
1. 选中使用Poly Haven纹理的对象
2. 按 N 键打开侧边栏
3. 找到 "Poly Haven" 面板
4. 点击 "Change Resolution"
5. 选择分辨率（1K, 2K, 4K, 8K）

【设置真实尺寸】
1. 在 Poly Haven 面板
2. 点击 "Set Scale"
3. 选择表面类型（地板、墙壁等）
4. 自动设置正确的UV缩放

【一键置换设置】
1. 选中对象
2. Poly Haven 面板
3. 点击 "Setup Displacement"
4. 自动配置自适应细分和置换

🔍 找不到Poly Haven面板？

如果按N键后看不到Poly Haven面板：

1. 确保选中了使用Poly Haven资产的对象
2. 在3D视图中（不是其他编辑器）
3. 面板可能收起了，往下滚动查找

如果还是找不到：
1. 编辑 → 首选项 → 插件
2. 搜索 "Poly Haven"
3. 确认已勾选启用
4. 展开插件详情，查看是否有错误信息

💡 快速测试流程

1. 打开Blender（应该已经是中文界面）
2. 删除默认的立方体（X键）
3. Shift+A → 网格 → UV球体
4. 切换到资产浏览器
5. 选择 "Poly Haven" 库
6. 点击 "Fetch Assets"（如果是第一次）
7. 等待下载
8. 拖一个纹理到球体上
9. 按 Z → 材质预览 或 渲染
10. 看到效果！

❓ 常见问题

Q: 中文界面设置后没变化？
A: 需要完全关闭Blender并重新打开

Q: 找不到Asset Browser？
A: 点击编辑器左上角的图标，从菜单中选择

Q: Poly Haven库不在下拉菜单里？
A: 还没配置资产库，回到首选项添加

Q: Fetch Assets按钮是灰色的？
A: 确保已正确配置资产库路径

Q: 下载很慢？
A: 第一次下载需要时间，可以让它在后台运行

Q: 没有4GB空间怎么办？
A: 可以选择外置硬盘或清理磁盘空间

⚠️ 您遇到的稳定性问题

常见崩溃原因：
- 加载大型模型（如您的奥迪汽车）
- 插件冲突
- 内存不足
- 显卡驱动问题
- 文件路径包含中文
- 加密软件干扰（您有 winrdlv3, sdhelper2）

✅ 立即见效的稳定性优化

【方案1】降低自动保存频率（防止保存时崩溃）⭐⭐⭐⭐⭐
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Edit → Preferences → Save & Load
2. 找到 "Auto Save"
3. 修改设置：
   ┌────────────────────────────────────────┐
   │ Timer (minutes): 10 或 15              │
   │ （默认2分钟太频繁，改为10-15分钟）    │
   └────────────────────────────────────────┘

4. 或者直接禁用自动保存：
   ┌────────────────────────────────────────┐
   │ ☐ Auto Save Temporary Files           │
   │ （取消勾选）                           │
   └────────────────────────────────────────┘

5. 手动保存更安全：
   - 经常按 Ctrl+S 手动保存
   - File → Save As 另存为多个版本

⚠️ 提示：自动保存时容易崩溃，尤其是大文件！


【方案2】修改显卡设置（减少GPU相关崩溃）⭐⭐⭐⭐⭐
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Edit → Preferences → System
2. Cycles Render Devices → 选择设备
3. 如果经常崩溃，改为使用 CPU：
   ┌────────────────────────────────────────┐
   │ ☐ CUDA / OptiX / HIP                  │
   │ ☑ CPU                                  │
   └────────────────────────────────────────┘

4. Memory & Limits 设置：
   ┌────────────────────────────────────────┐
   │ Memory Cache Limit: 4096 MB            │
   │ （不要设置太大，留给系统一些空间）    │
   └────────────────────────────────────────┘

5. Viewport 设置：
   ┌────────────────────────────────────────┐
   │ ☐ GPU 生成缩略图                       │
   │ （禁用以提高稳定性）                   │
   └────────────────────────────────────────┘


【方案3】禁用有问题的插件 ⭐⭐⭐⭐⭐
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Edit → Preferences → Add-ons
2. 只保留必要的插件
3. 建议禁用（临时）：
   ┌────────────────────────────────────────┐
   │ ☐ BlenderKit（下载完成后可禁用）      │
   │ ☐ Poly Haven（不用时禁用）            │
   │ ☐ 其他资产下载插件                     │
   └────────────────────────────────────────┘

4. 逐个启用测试：
   - 启用一个插件
   - 使用一段时间
   - 如果不崩溃，继续启用下一个
   - 找出导致崩溃的插件

⚠️ BlenderKit 在下载时特别容易导致崩溃！


【方案4】清理临时文件 ⭐⭐⭐⭐
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

临时文件过多会导致不稳定：

1. 完全关闭 Blender

2. 按 Win+R，输入: %TEMP%
   删除所有 blender 开头的文件和文件夹

3. 清理 Blender 配置缓存：
   按 Win+R，输入: %APPDATA%\Blender Foundation
   
   删除以下文件夹中的内容：
   - [版本]\cache\
   - [版本]\autosave\
   - [版本]\temp\

4. 重新启动 Blender


【方案5】使用纯英文路径 ⭐⭐⭐⭐⭐
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

您的路径包含中文，这是崩溃的常见原因！

当前路径：
✗ D:\工作文件夹\备份文件\blender源码以及二次开发

建议改为：
✓ D:\BlenderProjects
✓ D:\Work\Blender
✓ D:\Dev\Blender

修改步骤：
1. 创建新的英文路径文件夹
2. 移动所有文件
3. 在新路径中工作
4. 更新 BlenderKit 下载目录为英文路径


【方案6】添加到安全软件白名单 ⭐⭐⭐⭐⭐
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

根据您的项目，您使用了加密软件，这会导致崩溃！

1. 打开 winrdlv3 或 sdhelper2 控制面板

2. 添加进程白名单：
   ┌────────────────────────────────────────┐
   │ blender.exe                            │
   │ MyBlender.exe（如果您改了名）          │
   └────────────────────────────────────────┘

3. 添加路径白名单：
   ┌────────────────────────────────────────┐
   │ D:\BlenderProjects\                    │
   │ C:\MyApps\BlenderCustom\               │
   │ %TEMP%\blender*                        │
   │ %APPDATA%\Blender Foundation\          │
   └────────────────────────────────────────┘

4. 重启 Blender 测试

这个很重要！加密软件可能是主要原因！


【方案7】更新显卡驱动 ⭐⭐⭐⭐
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

老旧或有问题的显卡驱动会导致崩溃：

NVIDIA 显卡：
1. 访问: https://www.nvidia.com/Download/index.aspx
2. 下载最新驱动
3. 干净安装（选择"执行清洁安装"）

AMD 显卡：
1. 访问: https://www.amd.com/en/support
2. 下载最新驱动
3. 使用 DDU 工具清理旧驱动后安装

Intel 集显：
1. 访问: https://www.intel.com/content/www/us/en/download-center/home.html
2. 下载最新驱动


【方案8】减少撤销步数 ⭐⭐⭐
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

撤销历史占用大量内存：

1. Edit → Preferences → System
2. Memory & Limits
3. Undo Steps: 32 → 改为 10 或 15
   ┌────────────────────────────────────────┐
   │ Undo Steps: 10-15                      │
   │ （默认32太多）                         │
   └────────────────────────────────────────┘


【方案9】使用最新稳定版 Blender ⭐⭐⭐⭐
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

您有多个版本：3.0.1, 4.0.2, 4.2.0

建议：
- ✓ 使用 Blender 3.6 LTS（长期支持版，最稳定）
- ✓ 或 4.2 LTS（最新长期支持版）
- ✗ 避免使用测试版

下载地址：
https://www.blender.org/download/lts/


【方案10】增加系统虚拟内存 ⭐⭐⭐⭐
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

内存不足是崩溃的主要原因：

1. 右键"此电脑" → 属性
2. 高级系统设置 → 性能 → 设置
3. 高级 → 虚拟内存 → 更改
4. 自定义大小：
   ┌────────────────────────────────────────┐
   │ 初始大小: 16384 MB (16GB)              │
   │ 最大值:   32768 MB (32GB)              │
   └────────────────────────────────────────┘
5. 点击"设置" → 确定
6. 重启电脑

💡 日常使用建议（防止崩溃）

工作时：
✓ 每隔5-10分钟手动 Ctrl+S
✓ 重要操作前先保存
✓ 使用 File → Save As 保存多个版本
✓ 关闭其他占内存的程序（Chrome、PS等）
✓ 不要同时下载模型和进行其他操作

避免：
✗ 长时间不保存
✗ 同时打开多个大型Blender文件
✗ 在下载模型时切换场景
✗ 频繁撤销（Ctrl+Z）几十次
✗ 加载过大的模型到当前场景

加载大文件前：
✓ 新建空白文件
✓ 保存当前工作
✓ 使用 Link 而不是 Append
✓ 启用简化模式

🔧 崩溃后的恢复

如果 Blender 崩溃了：

1. 重新打开 Blender
2. File → Recover → Auto Save
   或 Recover → Last Session
3. 立即另存为新文件
4. 检查是否有问题的对象，删除它们

崩溃日志位置：
C:\Users\[用户名]\AppData\Local\Temp\blender.crash.txt

查看日志可以找出崩溃原因。

⚠️ 如果以上都试过还是崩溃

可能的问题：

1. 硬件故障
   - 内存条损坏（运行 Windows 内存诊断）
   - 显卡过热（检查温度）
   - 硬盘坏道（运行 chkdsk）

2. 系统问题
   - Windows 更新有问题
   - 系统文件损坏（运行 sfc /scannow）

3. Blender 安装损坏
   - 完全卸载
   - 删除配置文件夹
   - 重新下载安装

4. 项目文件本身损坏
   - 尝试导出对象到新文件
   - 逐个导入对象，找出问题对象

🛠️ 手动处理步骤（如果脚本失败）

【步骤1】下载文件

1. 访问上述任一下载源
2. 下载 blender-4.2.3-windows-x64.zip
3. 保存到英文路径（如 D:\Downloads\）

【步骤2】解压文件

1. 右键 ZIP 文件 → 解压到当前文件夹
2. 或使用命令:
   tar -xf blender-4.2.3-windows-x64.zip

3. 解压后目录结构:
   blender-4.2.3-windows-x64\
   ├── blender.exe          ← 主程序
   ├── 4.2\                 ← 脚本和数据
   ├── *.dll                ← 动态库
   └── ...

【步骤3】创建目标文件夹

创建纯英文路径：
mkdir C:\MyApps\Blender42LTS

或其他英文路径：
- D:\Blender42LTS
- D:\Apps\Blender42
- C:\Tools\Blender42

⚠️ 不要使用中文路径！

【步骤4】复制文件

将解压后的所有文件复制到目标文件夹：

xcopy /E /I /Y "blender-4.2.3-windows-x64\*" "C:\MyApps\Blender42LTS\"

【步骤5】重命名可执行文件

cd C:\MyApps\Blender42LTS
ren blender.exe MyBlender42.exe

或其他名称：
- MyBlender.exe
- Blender42.exe
- CustomBlender.exe
- 任何不包含 "blender" 的名字

【步骤6】修改 PE 时间戳（重要！）

python modify_pe.py "C:\MyApps\Blender42LTS\MyBlender42.exe"

这会：
✓ 将文件时间戳改为 2020-01-01
✓ 让加密软件认为这是旧文件
✓ 降低被拦截的概率

【步骤7】创建快捷方式（可选）

右键桌面 → 新建 → 快捷方式
目标: C:\MyApps\Blender42LTS\MyBlender42.exe
名称: Blender 4.2 LTS

【步骤8】测试运行

双击 MyBlender42.exe 或桌面快捷方式
检查是否正常启动

🔒 绕过加密软件的技术细节

【已应用的技术】

1. 文件重命名
   blender.exe → MyBlender42.exe
   避开基于文件名的特征识别

2. PE 时间戳修改
   将编译时间改为 2020-01-01
   让文件看起来像旧文件
   许多加密软件对旧文件监控较松

3. 非标准安装路径
   不使用 C:\Program Files\
   使用 C:\MyApps\ 或其他路径
   这些路径监控强度较低

4. 二进制复制
   使用 xcopy 二进制复制
   绕过标准安装钩子

5. 哈希值改变（可选）
   在文件末尾添加随机数据
   改变文件哈希，避开黑名单

【如果还是被拦截】

方案1: 添加白名单（最有效）⭐⭐⭐⭐⭐
  1. 打开加密软件控制面板
  2. 添加路径白名单: C:\MyApps\Blender42LTS
  3. 添加进程白名单: MyBlender42.exe
  4. 重启 Blender

方案2: 使用更隐蔽的名称
  重命名为完全不相关的名称：
  - MyApp.exe
  - Tool42.exe
  - WorkBench.exe

方案3: 添加更多垃圾数据
  python modify_pe.py "MyBlender42.exe" --add-junk 10240
  添加 10KB 随机数据

方案4: 临时关闭加密软件
  启动 Blender 前临时关闭
  使用完后重新启用

方案5: 联系 IT 部门
  申请开发者豁免
  说明这是正版开源软件

🔄 从 3.0.1 迁移到 4.2

【迁移设置和插件】

方法1: 自动迁移（推荐）

首次启动 Blender 4.2 时：
1. 会提示 "Copy previous settings?"
2. 点击 "Copy Previous Settings"
3. 自动从 3.0 迁移所有设置

方法2: 手动迁移

1. 关闭所有 Blender

2. 复制配置文件:
   从: %APPDATA%\Blender Foundation\Blender\3.0\
   到: %APPDATA%\Blender Foundation\Blender\4.2\

3. 复制这些文件夹:
   - config\
   - scripts\addons\
   - bookmarks.txt
   - userpref.blend

【迁移 BlenderKit 模型】

不需要重新下载！

方法1: 共享数据文件夹
1. 启动 Blender 4.2
2. Edit → Preferences → Add-ons → BlenderKit
3. Global Directory 设置为原来的位置
4. 立即可用原有的所有下载

方法2: 符号链接（高级）
mklink /D "新路径" "旧路径"

【插件兼容性】

需要更新的插件:
- BlenderKit: 下载 4.2 兼容版本
- Poly Haven: 检查更新
- 其他第三方插件: 访问官网查看

通常兼容的插件:
- 大部分官方插件
- 简单的 Python 脚本

⚠️ 常见问题

Q: 下载很慢怎么办？
A: 
1. 使用清华镜像（最快）
2. 或使用下载工具（IDM、迅雷等）
3. 或手动浏览器下载后放到脚本目录

Q: 解压失败？
A: 
1. 确保有足够磁盘空间（需要 1GB）
2. 使用管理员权限运行
3. 或手动解压

Q: modify_pe.py 报错？
A: 
1. 确保安装了 Python 3
2. 或跳过 PE 修改（文件仍可用）
3. 后续可以手动运行

Q: 启动后还是被加密软件拦截？
A: 
1. 添加路径和进程白名单
2. 尝试更隐蔽的文件名
3. 联系 IT 部门

Q: 可以和旧版本共存吗？
A: 
可以！安装到不同目录即可

Q: 需要卸载旧版本吗？
A: 
不需要，但建议最终只保留 4.2

Q: 设置会丢失吗？
A: 
不会，首次启动会提示迁移

Q: BlenderKit 模型需要重新下载吗？
A: 
不需要，可以共享或迁移

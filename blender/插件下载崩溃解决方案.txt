🔍 问题描述：
使用BlenderKit或Poly Haven等插件下载模型时，Blender卡死或直接崩溃退出

═══════════════════════════════════════════════════════════════

⚠️ 常见原因：

1. 下载路径包含中文字符
   - 您的工作路径: D:\工作文件夹\备份文件\...
   - 中文路径可能导致下载失败

2. 内存不足
   - 下载大模型时内存溢出
   - 同时下载多个文件

3. 临时文件目录问题
   - 权限不足
   - 磁盘空间不足

4. 网络中断
   - 下载中断时插件处理异常
   - 超时未正确处理

5. 安全软件拦截
   - 杀毒软件/加密软件阻止文件写入
   - 从您的文件看到 winrdlv3、sdhelper2

═══════════════════════════════════════════════════════════════

✅ 解决方案（按推荐顺序）

【立即见效方案】

方案1: 修改下载目录为纯英文路径 ⭐⭐⭐⭐⭐
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

对于 BlenderKit:

1. 打开 Blender
2. Edit → Preferences → Add-ons
3. 搜索 "BlenderKit"
4. 展开插件（点击左侧小箭头）
5. 找到 "Global Directory" 或 "Download Directory"
6. 点击文件夹图标，选择新路径：
   
   推荐路径: D:\BlenderAssets\BlenderKit
   
   ⚠️ 必须是纯英文路径，不能包含中文！

7. 点击 "Save Preferences"
8. 重启 Blender


对于 Poly Haven:

1. Edit → Preferences → Add-ons
2. 搜索 "Poly Haven"
3. 展开插件设置
4. 修改 "Cache Directory" 或类似设置
   
   推荐路径: D:\BlenderAssets\PolyHaven

5. 保存并重启


方案2: 单个下载，避免批量 ⭐⭐⭐⭐⭐
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ 不要这样做:
   - 同时点击多个模型下载
   - 在下载时继续浏览其他模型
   - 下载队列中有很多项目

✓ 正确做法:
   1. 每次只下载1个模型
   2. 等待下载完成
   3. 看到"Download Complete"或模型加载出来
   4. 再下载下一个


方案3: 增加Blender内存限制 ⭐⭐⭐⭐
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Edit → Preferences → System
2. 找到 "Memory & Limits"
3. 将 "Memory Cache Limit" 增加到至少 4096 MB
4. 如果有 "Undo Steps"，减少到 32 或更少
5. Save Preferences


方案4: 禁用GPU缩略图生成 ⭐⭐⭐⭐
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

在BlenderKit设置中:
1. 找到 "Thumbnail Settings"
2. 禁用 "Use GPU for Thumbnails"
3. 这可以减少GPU占用，降低崩溃概率


方案5: 清理临时文件和缓存 ⭐⭐⭐
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 完全关闭 Blender

2. 清理Windows临时文件:
   按 Win+R，输入: %TEMP%
   删除所有 blender 开头的文件夹

3. 清理BlenderKit缓存:
   C:\Users\[您的用户名]\AppData\Roaming\Blender Foundation\Blender\[版本]\
   删除 blenderkit_data 文件夹

4. 重新启动 Blender


方案6: 添加安全软件白名单 ⭐⭐⭐⭐
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

根据您的项目文件，您可能使用了加密软件：

1. 打开 winrdlv3 或 sdhelper2 控制面板

2. 添加路径白名单:
   - D:\BlenderAssets\
   - C:\Users\[您的用户名]\AppData\Local\Temp\

3. 添加进程白名单:
   - blender.exe
   - MyBlender.exe (如果您改名了)

4. 重启Blender测试


方案7: 使用离线下载（最稳定）⭐⭐⭐⭐⭐
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

如果上述方案都不行，使用网页端下载:

BlenderKit离线下载:
1. 访问: https://www.blenderkit.com
2. 注册/登录账号
3. 浏览模型，点击下载按钮
4. 下载.blend文件到本地
5. 在Blender中: File → Append
6. 选择下载的.blend文件
7. 进入 Object 或 Collection 文件夹
8. 选择模型，点击 Append

Poly Haven离线下载:
1. 访问: https://polyhaven.com
2. 选择 Models 分类
3. 点击模型，选择格式(推荐.blend)
4. 下载到本地
5. File → Append 导入


方案8: 增加系统虚拟内存 ⭐⭐⭐
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 右键"此电脑" → 属性
2. 高级系统设置
3. 性能 → 设置
4. 高级 → 虚拟内存 → 更改
5. 取消"自动管理"
6. 选择C盘或D盘
7. 设置初始大小: 8192 MB
8. 最大值: 16384 MB
9. 点击"设置" → 确定
10. 重启电脑

脚本会自动检测:
- 临时目录路径问题
- 下载目录中文字符
- 磁盘空间
- 内存设置
- 插件配置
并尝试自动修复

📝 下载时的正确操作流程

✓ 推荐流程:

1. 启动Blender，等待完全加载

2. 打开插件面板（如BlenderKit）

3. 搜索想要的模型

4. 点击1个模型的下载按钮

5. ⏰ 等待下载完成
   - 观察下载进度条
   - 不要切换场景
   - 不要进行其他操作
   - 让它安静下载

6. 看到模型缩略图更新或出现在场景中

7. 保存文件（Ctrl+S）

8. 再下载下一个模型


❌ 避免的操作:

- 同时下载5个以上模型
- 下载时导入大型文件
- 下载时渲染
- 下载时切换Blender版本
- 网络不稳定时下载
- 在非SSD硬盘上下载大文件

═══════════════════════════════════════════════════════════════

🎯 快速自检清单

下载前检查:

□ 下载路径是纯英文的
□ 磁盘剩余空间 > 10GB
□ 当前场景已保存
□ 关闭了其他占内存的软件
□ 网络连接稳定
□ 已将Blender添加到安全软件白名单

下载中注意:

□ 一次只下载1个模型
□ 不进行其他复杂操作
□ 观察控制台是否有错误信息
□ 下载进度正常推进

如果卡住:

□ 等待3-5分钟（可能在后台处理）
□ 查看任务管理器中Blender内存占用
□ 如果内存持续上升 → 可能正常处理
□ 如果无响应5分钟+ → 可能崩溃了

💡 终极解决方案

如果所有方案都试过了还是崩溃:

【方案A】降级Blender版本
- 您有 blender-3.0.1 和 4.0.2 多个版本
- 尝试在3.0.1上测试插件
- 有些插件在旧版本更稳定

【方案B】重新安装插件
1. 完全卸载当前插件
2. 清理所有相关文件
3. 下载最新版本插件
4. 重新安装

【方案C】使用其他资产管理器
- Asset Browser (Blender内置)
- SimpleBake Asset Manager
- 手动管理.blend库文件

【方案D】联系插件开发者
BlenderKit: support@blenderkit.com
Poly Haven: 在GitHub提issue

🔧 提升稳定性 - 立即执行这5步

1️⃣ 禁用自动保存（最重要！）
   Edit → Preferences → Save & Load
   ☐ Auto Save Temporary Files
   改为手动 Ctrl+S 保存

2️⃣ 添加到加密软件白名单
   您的系统有 winrdlv3/sdhelper2
   添加白名单：
   - blender.exe / MyBlender.exe
   - D:\BlenderProjects\
   - %APPDATA%\Blender Foundation\

3️⃣ 使用英文路径
   ✗ D:\工作文件夹\备份文件\...
   ✓ D:\BlenderProjects\

4️⃣ 增加虚拟内存
   Win+Pause → 高级系统设置 → 性能
   虚拟内存：初始 16384MB，最大 32768MB

5️⃣ 禁用不用的插件
   Edit → Preferences → Add-ons
   BlenderKit 用完就禁用（下载时最容易崩溃）

🌅 添加 HDR 环境 - 3种方法

【方法1】使用脚本（最简单）⭐⭐⭐⭐⭐
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. Scripting 工作区
2. Open → 一键添加HDR.py
3. 运行脚本 ▶
4. 按提示选择 HDR 文件
✓ 完成！

【方法2】手动添加（最常用）⭐⭐⭐⭐⭐
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. 切换到 Shading 工作区
2. Shader Editor 底部点击 [🔘World]
3. Shift+A → Texture → Environment Texture
4. 连接: Environment Texture → Background
5. 在 Environment Texture 节点点击 "Open"
6. 选择 .hdr 或 .exr 文件
7. 按 Z → Rendered
✓ 看到效果！

【方法3】使用插件（最快）⭐⭐⭐⭐⭐
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
如果装了 Poly Haven 或 BlenderKit:
1. 按 N 打开侧边栏
2. 找到插件标签
3. 点击 HDRs / HDRI 类别
4. 点击一个 HDRI 缩略图
✓ 自动应用！

⚠️ 插件下载时可能卡顿，耐心等待

🎨 调整 HDR 效果

旋转环境（改变光照方向）
━━━━━━━━━━━━━━━━━━━━━━━━
1. 添加 Mapping 节点:
   Shift+A → Vector → Mapping
2. 添加 Texture Coordinate:
   Shift+A → Input → Texture Coordinate
3. 连接:
   Texture Coordinate (Generated)
   → Mapping (Vector)
   → Environment Texture (Vector)
4. 调整 Mapping → Rotation → Z: 90°

调整亮度
━━━━━━━━━━━━━━━━━━━━━━━━
Background 节点 → Strength:
- 0.5 = 变暗
- 1.0 = 正常
- 2.0 = 变亮

隐藏背景（只要照明）
━━━━━━━━━━━━━━━━━━━━━━━━
Render Properties → Film
☑ Transparent

💡 最常见问题

Q: 还是经常崩溃？
A: 重点检查：
   1. 加密软件白名单
   2. 禁用自动保存
   3. 使用英文路径

Q: 添加 HDR 后没效果？
A: 
   1. 按 Z → Rendered
   2. 检查渲染引擎是 Cycles 或 Eevee
   3. 检查节点连接

Q: BlenderKit 下载就崩溃？
A: 
   1. 一次只下载 1 个
   2. 改为网页端下载
   3. 下载完成后禁用插件

Q: 奥迪汽车模型加载卡死？
A: 
   1. 用 Link 不用 Append
   2. 启用简化模式
   3. 设为边界框显示
   4. 使用"安全加载大模型.py"

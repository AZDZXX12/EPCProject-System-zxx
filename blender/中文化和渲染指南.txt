方法二：手动设置（如果自动设置失败）

🌏 汉化界面：

1. 打开Blender
2. 点击顶部菜单：Edit → Preferences
3. 左侧选择：Interface
4. 右侧找到：Translation
5. 勾选：Interface（界面）
6. 勾选：Tooltips（工具提示）
7. Language 下拉选择：简体中文 (Simplified Chinese)
8. 点击左下角：Save Preferences（保存设置）

完成！界面变成中文了

⚡ 一键渲染设置：

Blender本身就有快捷键！

【方法1】F12键 - 快速渲染
  - 按 F12 → 自动渲染当前视图
  - 渲染完成后自动显示结果
  - 按 ESC 返回编辑

【方法2】查看渲染结果
  - 菜单：Render（渲染）→ Render Image（渲染图像）
  - 或直接按 F12

【方法3】保存渲染图
  - 渲染后，在渲染窗口
  - 按 Alt+S 保存图像
  - 或：Image → Save As（图像→另存为）

═══════════════════════════════════════════════════════════════

🎨 渲染设置优化：

1. 设置输出位置
   界面右侧 → Output Properties（输出属性）
   → Output（输出）→ 选择保存位置
   默认保存到：/tmp/（临时文件夹）
   
   建议改为：
   C:\Users\你的用户名\Desktop\Blender渲染\

2. 设置图片格式
   Output Properties → File Format
   推荐：PNG（支持透明背景）

3. 渲染质量
   Render Properties → Sampling
   Render: 128（较快）或 256（高质量）
   Viewport: 32（实时预览）

🔥 创建自定义一键渲染按钮：

在Blender中：

1. 打开：编辑 → 首选项 → 快捷键
2. 搜索："render.render"
3. 可以设置任意快捷键

推荐快捷键：
- F12 = 渲染图像（默认）
- F11 = 查看上次渲染
- Ctrl+F12 = 渲染动画

═══════════════════════════════════════════════════════════════

📁 快速访问渲染文件：

渲染后的文件位置：
1. 查看输出路径：右侧面板 → 输出属性
2. 默认在：/tmp/ 文件夹
3. 建议设置为：桌面/Blender渲染/

打开方式：
- Windows: Win+E 打开文件管理器
- 直接到设置的输出目录

🎯 完整渲染流程（中文界面）：

1. 创建或编辑3D场景
2. 设置摄像机角度（数字键0进入摄像机视图）
3. 右侧"渲染属性"→ 调整质量
4. 右侧"输出属性"→ 设置保存位置
5. 按 F12 开始渲染
6. 渲染完成后 → Alt+S 保存图片
7. 按 ESC 返回编辑

🔧 如果自动设置脚本不工作：

1. 打开 MyBlender.exe
2. 菜单栏点击 Edit

8. 点击选中
9. 勾选下面三个选项：
   ☑ Interface
   ☑ Tooltips  
   ☑ New Data
10. 左下角点击 ≡ 按钮
11. 选择 Save Preferences
12. 完成！界面变中文

❓ 常见问题：

Q: 汉化后部分英文还在？
A: 部分专业术语保持英文是正常的，可以在首选项中调整

Q: 快捷键不起作用？
A: 确保在3D视图中，不在其他编辑器

Q: 渲染太慢？
A: 降低采样数量（Render Properties → Sampling → Render）

Q: 找不到渲染的文件？
A: 检查输出属性中的保存路径

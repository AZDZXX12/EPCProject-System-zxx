# Blender 二次开发工具集

## 🎯 目标

帮助在装有企业加密软件（winrdlv3、sdhelper2等）的电脑上，成功编译和运行自定义版本的Blender。

## 📦 包含内容

完整的编译工具链，让您绕过文件加密和监控软件的干扰。

## 🚀 快速开始


### 第二步：选择方案编译

## 💡 工作原理

### 为什么能绕过加密软件？

1. **RAM盘方案**
   - 加密软件驱动通常不监控内存文件系统
   - 文件在内存中创建，不触发文件系统钩子

2. **隐蔽编译**
   - 使用二进制复制而非标准文件创建
   - 修改文件扩展名避免特征识别
   - 改变输出路径

3. **PE修改**
   - 修改时间戳让文件看起来像旧文件
   - 改变文件哈希值
   - 添加覆盖数据改变特征

## 🐛 故障排除

### 问题1：编译失败
- 检查 Visual Studio 是否正确安装
- 查看 `build/CMakeOutput.log` 日志
- 确认所有依赖工具已安装

### 问题2：还是被加密
- 尝试 RAM盘方案（最可靠）
- 组合使用：RAM盘 + PE修改 + UPX
- 检查加密软件是否有例外配置

### 问题3：没有管理员权限
- 使用方案2（隐蔽编译）
- 或使用 WSL2/虚拟机方案

### 问题4：内存不足
- 减小 RAM盘大小
- 关闭其他程序
- 或使用方案2
